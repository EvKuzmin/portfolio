## О репозитории

`portfolio` — это коллекция разноплановых проектов:

- **Веб**: простые страницы и стили (`index.html`, `style.css`)
- **Python**: утилиты, Telegram-бот, API-эксперименты
- **C++/HPC**: численные методы, разреженные матрицы, multigrid/solver-проекты

## Структура

Ниже перечислены основные директории верхнего уровня:

- **BotHelper/** — Telegram-бот и связанные модули (`handlers.py`, `keyboards.py`, `main.py`)
- **inmost_stokes_par_mg_new/** — крупный C++ проект (CMake, PETSc, multigrid, решатели)
- **IVMiMG/** — набор экспериментов/модулей по численным методам
- **laplace_armadillo/** — C++ проект с CMake для задач типа Лапласа
- **Scopus_api_test/** — Python-скрипты для работы с API и тестовых запросов
- **SPAI/** — реализация/эксперименты с SPAI
- **SystemSolver/** — материалы, связанные с решателями систем

> Структура репозитория исследовательская: внутри подпроектов могут быть собственные `README`, `CMakeLists.txt`, конфиги и отдельные входные точки.

## Быстрый старт

### 1) Клонирование

```bash
git clone <repo-url>
cd portfolio
```

### 2) Python-проекты

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если `requirements.txt` отсутствует в корне, смотрите зависимости в конкретной подпапке проекта.

### 3) C++/CMake-проекты

Общая схема сборки:

```bash
cmake -S . -B build
cmake --build build --config Release
```

Для крупных проектов (например, с PETSc/INMOST) убедитесь, что системные зависимости установлены заранее.
